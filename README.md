
# AFS-RIME-XGBoost untuk Prediksi Temperatur Rotor PMSM

Repositori ini berisi kode program dan data pendukung
penelitian mengenai pengaruh Adaptive Feature Selection
(AFS) berbasis Binary-RIME terhadap kinerja RIME-XGBoost
dalam prediksi temperatur rotor PMSM.

## Isi Repositori

1. AFS_RIME_XGBoost_PMSM_Final.ipynb
   Kode praproses, rekayasa fitur, seleksi fitur,
   optimasi hyperparameter, dan evaluasi model.

2. Lampiran_Optimasi_AFS_RIME_XGBoost.xlsx
   Riwayat fitness Binary-RIME, hasil konvergensi
   RIME-XGBoost, frekuensi seleksi fitur,
   dan analisis stabilitas menggunakan Jaccard.

## Dataset

Electric Motor Temperature Dataset
Sumber: Kaggle - wkirgsn/electric-motor-temperature
